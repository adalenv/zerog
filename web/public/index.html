CLI Quick Guide

zerog

Launch interactive agy session with automatic account rotation.

Run a prompt turn; automatically retries with next account if quota limit is met.

zerog accounts

View all accounts, statuses, and active failover priority.

zerog daemon start

Start background watcher for IDEs and direct CLI invocations.

Sign In Another Google Account

To register another Google account in the zerog pool:

  1. Choose an identifier (e.g. work, personal2).
  2. Run the login command below in your terminal. It backs up your active session and launches the browser to sign in.
  3. Once authenticated, zerog captures the token into your pool!
zerog login second-account
